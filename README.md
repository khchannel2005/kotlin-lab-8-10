# kotlin-lab-2-9

## Опис

Цей проєкт об'єднує **лабораторні роботи №2–6, №8 та №9** в один повноцінний застосунок. Доменна область – **база даних спортзалу**, яка дозволяє керувати користувачами, абонементами та тренуваннями.

## Реалізовано

- **Лабораторні №2–6:**
  - Створено простий Spring Boot застосунок із одним REST-контролером.
  - Реалізовано API для отримання списку об'єктів (користувачів).
  - Додано сервісний рівень для обробки бізнес-логіки.
  - Реалізовано API для додавання та отримання об'єктів.

- **Лабораторна №8:**
  - Підключення до бази даних через Spring Data JPA.
  - Реалізація CRUD-операцій (Create, Read, Update, Delete).
  - Використано анотації для налаштування відносин між сутностями (`@OneToMany`, `@ManyToOne`).
  - Додано спеціалізовані запити через методи репозиторіїв.

- **Лабораторна №9:**
  - Ознайомлення з основами юніт-тестування.
  - Написано юніт-тести для методів сервісу.
  - Налаштовано використання JUnit для тестування.

## Технології

- Kotlin
- Spring Boot
- Spring Data JPA
- H2 Database
- JUnit 5 + MockK
